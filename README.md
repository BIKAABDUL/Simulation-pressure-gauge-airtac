# Simulator AirTAC DPS (latihan setting)

Simulator latihan untuk pressure sensor AirTAC DPSN1-10 yang terpasang di FRL GFC300-10, dalam Bahasa Indonesia dan Mandarin (简体中文).
Isinya: reset pabrik, setting mode output, batas tekanan 1-H / 1-L / 2-P, knob regulator, dan panel OUT1/OUT2.

Buka `index.html` di browser, atau lewat GitHub Pages. Tidak perlu internet setelah halaman terbuka.

Simulator latihan independen, bukan aplikasi resmi AirTAC. Selalu cek manual resmi alat sebelum mengubah setting di mesin.
